Proyecto Data Analytics – Coderhouse

📌 Descripción del proyecto

Este repositorio contiene los trabajos realizados durante mi formación en Data Analytics en Coderhouse.

El objetivo es aprender a organizar, consultar, limpiar y analizar datos de ventas de una empresa de tecnología, utilizando herramientas como SQL Server y Power BI.

🗄️ Base de datos: Ventas_Tech_DB

En este proyecto trabajo con una base de datos llamada Ventas_Tech_DB, que contiene información sobre clientes, productos, categorías y ventas.

Esta información permite realizar consultas para conocer el comportamiento de las ventas y obtener datos útiles para la toma de decisiones.

📚 Trabajos realizados

Módulo 3 – Creación de la base de datos

Creación de la base de datos Ventas_Tech_DB en SQL Server.

Creación de tablas y definición de relaciones.

Carga de datos iniciales.

Archivo: ventas_tech_db.sql

Módulo 4 – Consultas de negocio

Consultas SQL para analizar información de ventas.

Uso de filtros, agrupaciones y funciones de agregación.

Obtención de resultados para responder preguntas de negocio.

Archivo: m4_consultas_negocio.sql

Módulo 5 – Consultas con JOIN

Uso de INNER JOIN para combinar información de distintas tablas.

Uso de LEFT JOIN para identificar clientes y productos sin ventas.

Uso de UNION ALL para combinar resultados.

Preparación de información para futuros análisis en Power BI.

Archivo: m5_consultas_joins.sql

▶️ Cómo ejecutar los archivos SQL

Abrir SQL Server Management Studio (SSMS).

Conectarse a una instancia de SQL Server.

Abrir y ejecutar primero ventas_tech_db.sql para crear la base de datos y sus tablas.

Ejecutar m4_consultas_negocio.sql para consultar los datos de negocio.

Ejecutar m5_consultas_joins.sql para realizar las consultas con JOIN y UNION ALL.

Importante: los scripts deben ejecutarse en ese orden, ya que las consultas de los módulos 4 y 5 utilizan la base de datos creada en el módulo 3.
